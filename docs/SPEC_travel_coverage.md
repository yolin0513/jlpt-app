# SPEC：生活旅行情境覆蓋盤點（草稿）

- **狀態**：規劃中，尚未動工。2026-09-03 與「N2/N1 例句品質抽查」同時規劃，一樣被後續工作擠掉。
- **背景**：生活旅行分類自 v1.2.0（2026-09-03）之後內容沒動過：
  情境會話 142 條、日本人這樣說 54 條、中日漢字大不同 70 條，共 266 條。
  Yolin 的定位是讓台灣人更貼近日本人的實際用法，並**支援自由行**。
- **優先度建議**：中。對 Yolin 的實際旅行有直接幫助，工作量中等、不動資料結構。

## 做法

1. 列出自由行的完整流程（出入境、交通、住宿、飲食、購物、觀光、就醫、緊急狀況…），對照現有 `data/src/travel.phrases.txt` 的情境欄，找出缺口。
2. **候選方向**（只是候選，每項都要先查證是否已收錄）：溫泉／錢湯、寺社參拜、租車與加油、郵局與宅配、電話預約、地震與災害廣播、IC 卡加值、藥妝店詢問、退稅。
3. 新條目**一律加在檔尾**（id 依行序）；格式與維護方式見 README「增補生活旅行內容」。
4. 正確性第一：Yolin 特別要求「漢字差異的日文語義與讀音」要準；新增後人工抽樣核對。
