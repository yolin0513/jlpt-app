# JLPT 練習 — 日文檢定 N1–N5＋生活旅行

**線上版：https://yolin0513.github.io/jlpt-app/**（手機開啟後可「加入主畫面」安裝，安裝後可離線使用）

手機優先的 **PWA**（漸進式網頁應用程式），用來練習 JLPT N1～N5 的**單字**與**文法**，
另附一組與級別無關的**生活旅行用語**（情境會話、日本人實際用法、中日漢字差異）。
可加到手機主畫面、支援離線使用，所有學習資料只存在你的瀏覽器裡，不需要註冊、不需要後端伺服器。

介面語言為**繁體中文**，日文內容皆標註**假名讀音**。

---

## 功能

| 功能 | 說明 |
| --- | --- |
| 🃏 閃卡背誦 | 正面日文（漢字）、翻卡看假名／中文釋義／例句，並自我評分（不會／模糊／認得） |
| 📝 四選一測驗 | 日→中、中→日、文法↔意思等多種出題方向，作答後即時顯示解說與例句 |
| 🔁 間隔重複（SRS） | Leitner box 制：答對逐步拉長複習間隔（10 分鐘 → 1 → 2 → 4 → 8 → 16 → 32 天），答錯歸零並排入近期複習 |
| ❗ 錯題本 | 測驗／閃卡答錯的項目自動收錄，可依級別／類型篩選、單獨練習、掌握後自動標記訂正 |
| 🧳 生活旅行 | 與 JLPT 平行的獨立分類，見下方專節。同樣支援閃卡、測驗、SRS、錯題本，統計分開顯示 |
| ★ 重點複習 | 在任何地方點 ☆ 收藏單字／文法／旅行用語，集中以閃卡或測驗複習 |
| 🔍 搜尋 | 跨全部級別＋生活旅行即時搜尋漢字、假名、羅馬字或中文釋義；結果可直接收藏、朗讀 |
| 🔊 日文朗讀 | 以 Web Speech API 朗讀日文（單字例句、文法例句），可設定翻卡時自動朗讀。完全在裝置端運作 |
| 📊 學習統計 | 每日學習量（近 14 天長條圖）、各級別掌握度、總正確率、連續學習天數 |
| 🎯 每日目標 | 可自訂每日題數目標（預設 20），首頁顯示達成進度 |
| ⌨️ 鍵盤快捷鍵 | 測驗：`1`–`4` 選項、`Enter`/`空白` 下一題、`S` 朗讀；閃卡：`空白` 翻卡、`1`/`2`/`3` 評分、`S` 朗讀、`Esc` 結束 |
| 🌓 深色 / 淺色 | 手動切換，預設跟隨系統 |
| 💾 資料匯出 / 匯入 | 以 JSON 備份或轉移學習進度（含最愛）；可一鍵重置 |
| 👋 首次引導 | 初次開啟時顯示簡短使用說明 |

### 出題範圍選項
- **智慧（新題優先）**：未學過 → 已到期 → 其他
- **隨機**
- **依序**：照題庫順序

出題來源除了「指定級別題庫」外，也可從**待複習項目**、**錯題本**、**重點複習**、**生活旅行分類**組卷。

## 生活旅行用語（與 JLPT 平行的分類）

首頁「生活旅行用語」入口，或 `#/travel`。內容與 JLPT 級別完全獨立（進度、統計分開計算），
但共用閃卡、四選一測驗、間隔重複與錯題本。分成三塊：

| 分類 | 內容 | 練習時 |
| --- | --- | --- |
| 💬 情境會話 | 機場入境／領行李、電車／巴士／計程車、住宿 check-in/out 與客訴、餐飲進店／點餐／用餐／結帳、購物／退稅、藥妝店、便利商店、問路、生病、遺失物品與報警等自由行實用句 | 正面看中文情境 → 翻卡／選出對應日文（含假名）。可再依「情境」細分練習 |
| 🗣️ 日本人這樣說 | 店員的固定問句（加熱？袋子？集點卡？內用外帶？）與你該怎麼回、居酒屋「お通し」、電車站內廣播、以及「課本 vs 現實」的委婉說法（お手洗い／〜ていただけますか／けっこうです…） | 同上，備註欄提示「你可以這樣回應」 |
| 🀄 中日漢字大不同 | 同一漢字在中日文語義落差大的詞，逐條列「日文讀音／日文意思／台灣人常誤解成什麼／例句」。例：**床**（日文＝地板，不是睡覺的床）、手紙（信）、勉強（唸書）、汽車（蒸汽火車）、丈夫（結實）、大家（房東）、切手（郵票）、人参（紅蘿蔔）、迷惑（困擾）、階段（樓梯）、無理、心中（殉情）、新聞（報紙）、精進、油断、愛人（情婦）、放心（發呆）、留守（不在家）… | 正面看漢字 → 翻卡／選出日文意思；或反向由意思選漢字 |

目前份量：情境會話 142 條、日本人這樣說 54 條、中日漢字大不同 70 條，共 266 條。

### 增補生活旅行內容

| 檔案 | 每行格式 |
| --- | --- |
| `data/src/travel.phrases.txt` | `場景 \| 日文 \| 假名 \| 中文 \| 備註(可空)` |
| `data/src/travel.usage.txt` | `場景 \| 日文 \| 假名 \| 中文 \| 你可以這樣說／說明(可空)` |
| `data/src/travel.kanji.txt` | `漢字 \| 日文讀音 \| 日文意思 \| 台灣人常誤解 \| 例句 \| 例句假名 \| 例句中譯` |

編輯後同樣執行 `python scripts/build_data.py`（產生 `data/travel/*.json` 並更新 `manifest.json` 的 `travel` 區塊），
再跑 `python scripts/check_data.py` 檢查。id 為 `tv-p-0001`／`tv-u-0001`／`tv-k-0001`，新增請加在檔案末端。

## 技術棧

- 純 **原生 JavaScript（ES Modules）**，無框架、無打包工具
- **IndexedDB** 儲存學習進度、錯題、每日統計、最愛（DB 版本 2，升級只新增 store、不動舊資料）
- **Web Speech API** 提供裝置端日文朗讀（無網路需求）
- **Service Worker + Web App Manifest** 提供離線與「加入主畫面」能力
- 題庫為可擴充的 **JSON** 檔（由 `data/src/*.txt` 產生）
- 開發用靜態伺服器以 **Python 標準函式庫** 實作（`scripts/serve.py`）
- 題庫品質檢查腳本 `scripts/check_data.py`（欄位、假名、重複、抽樣）

> 之所以選這個組合：打開檔案就能改、學習曲線低、日後只要編輯純文字題庫再跑一行指令即可增補內容。

## 本機啟動

Service Worker 需要透過 `http(s)://`（或 `localhost`）載入，**不能用 `file://` 直接開啟**。任選一種方式起一個本機伺服器：

### 方式 A：專案內建伺服器（建議）

```bash
cd D:\Claude\App\JLPT_App
python scripts/serve.py            # 預設 http://localhost:5173
python scripts/serve.py 8000      # 或自訂埠號
```

內建伺服器為多執行緒，並設定正確的 MIME 類型與「不快取」標頭，適合開發。

### 方式 B：Python 內建模組

```bash
cd D:\Claude\App\JLPT_App
python -m http.server 5173
```

### 方式 C：Node

```bash
cd D:\Claude\App\JLPT_App
npx serve -l 5173
# 或： npx http-server -p 5173
```

開啟瀏覽器到 `http://localhost:5173/`。
用手機測試時，讓手機與電腦連同一個 Wi-Fi，開 `http://<電腦區域網路IP>:5173/`。

### 安裝到手機主畫面
- **iOS Safari**：分享 → 加入主畫面
- **Android Chrome**：選單 → 安裝應用程式 / 加入主畫面

安裝後首次連線會把 App 與題庫快取起來，之後即可離線使用。

### 產生畫面截圖（開發用）

```bash
npm install                       # 安裝 puppeteer（會下載一份 Chromium）
python scripts/serve.py 5173      # 另開一個視窗跑伺服器
node scripts/screenshots.mjs      # 產生 screenshots/*.png（手機尺寸 390x844）
```

腳本會先在瀏覽器裡塞一批示範學習紀錄，再依序截取首頁、學習、生活旅行、閃卡、
中日漢字閃卡、測驗、測驗結果、旅行測驗、錯題本、重點複習、複習、統計、搜尋、深色首頁。

## 如何增補題庫

題庫內容一律寫在 `data/src/` 的純文字檔，欄位以 `|`（或全形 `｜`）分隔，`#` 開頭為註解。

### 1. 單字：`data/src/vocab.<級別>.txt`

```
漢字 | 假名 | 中文釋義 | 詞性 | 例句(可空) | 例句假名(可空) | 例句中譯(可空)
```

範例：

```
勉強 | べんきょう | 學習、唸書 | 名詞 | 毎日日本語を勉強します。 | まいにちにほんごをべんきょうします。 | 每天學日語。
早い | はやい | 早的、快的 | 形容詞（い形） | 朝が早いです。 | あさがはやいです。 | 早上起得很早。
```

- 只有前三欄（漢字、假名、中文釋義）是必填，其餘可留白（`漢字 | かな | 意思 | | | |`）。
- 沒有漢字的詞（外來語等），漢字欄直接寫假名即可。

### 2. 文法：`data/src/grammar.<級別>.txt`

```
句型 | 讀音(可空) | 中文意思 | 接續結構 | 例句 | 例句假名 | 例句中譯
```

範例：

```
～たことがあります | | 「曾經～過」表示經驗 | 動詞た形＋ことがあります | 富士山に登ったことがあります。 | ふじさんにのぼったことがあります。 | 曾經爬過富士山。
```

### 3. 重新產生 JSON 並檢查

```bash
python scripts/build_data.py     # 產生 data/*.json 與 manifest.json
python scripts/check_data.py     # 檢查欄位缺漏、假名格式、重複條目、數量一致
python scripts/check_data.py --sample 30   # 另外隨機抽 30 條供人工核對
```

`build_data.py` 會依照各檔案目前的順序重新編號 id（`n5-v-0001`、`n3-g-0012`…），
並更新 `data/manifest.json` 的各級別數量。

`check_data.py` 會驗證：必填欄位（漢字／句型、中文釋義、詞性）不為空、假名欄只含假名、
有例句就要有例句假名、同級別內無重複條目（單字依 漢字＋假名、文法依句型）、
各 JSON 的 `count` 與 `manifest.json` 一致、全域 id 唯一。有問題會以非零結束碼回報。

> ⚠️ id 是依行序產生的。如果你在檔案**中間插入**新詞，後面所有詞的 id 會位移，
> 已學習者的進度紀錄會對不上那些位移的項目。建議**新增時往檔案末端加**（本專案增補的批次都放在各檔末尾的「=== 增補批次 N ===」註解之後）。

### 4.（選用）直接編輯 JSON

也可以略過 `data/src/` 直接改 `data/vocab/*.json` / `data/grammar/*.json` / `data/travel/*.json`，
只要維持既有欄位結構與唯一的 `id`，並同步更新 `data/manifest.json` 裡對應的 `count`。

### 新增一個全新級別檔的注意事項
`build_data.py` 只認得 `N5`–`N1` 與三個生活旅行分類。若某級別原本沒有檔案，新增 `data/src/vocab.n2.txt` 後再跑腳本即可，
`manifest.json` 會自動補上該組；`sw.js` 的預先快取清單已包含全部 10 個級別檔與 3 個生活旅行檔。
