## 現況

→ 新詞第一次答對**直接進 box 1（隔天）**。box 0 的「10 分鐘同場複習」只有答錯才會用到。
→ **同一項目要答對 3 次、最快跨 3 個日曆天（第 0、1、3 天）才算「已掌握」**。第一天做再多都不會有「已掌握」。
