## 2. 目標與非目標

**目標**：上表每一格都換成「改壞對應的程式就會紅」的斷言，而且紅的就是那一條。

**非目標**：不改任何功能、不改文案、不改版面；不動 `js/**`、`data/**`、`sw.js`（手動改壞驗紅時暫時改、驗完還原，不算）。**寫斷言的過程如果發現真的 bug，停下來回報，不要順手修。** 空池畫面的文案「沒有可測驗的項目」維持（Yolin 偏好不加新提示；你若認為該講出原因，寫進回報當提議）。
