- **狀態**：規劃中，尚未動工。2026-09-11 起在「下一批優化候選」裡提過三次，一直排在其他項目之後。

## 目的

讓使用者把「錯題本／弱點清單／重點收藏／指定級別」匯出成 Anki 可匯入的檔案，
在 Anki（手機或桌機）用它自己的排程繼續練。

## 建議做法

**用 Anki 的「文字檔匯入」（TSV），不要產 `.apkg`**：

| 做法 | 優點 | 缺點 |
| --- | --- | --- |
| **TSV（建議）** | 純前端 `Blob` 下載即可；零相依；Anki 桌機與 AnkiDroid 都能匯入 | 使用者要在 Anki 選欄位對應（可在檔頭用 `#separator:tab`、`#html:true`、`#columns:` 指令自動化） |
| `.apkg` | 一鍵匯入、可帶卡片樣式 | 要在瀏覽器產 SQLite + zip → 需新增相依套件（sql.js、JSZip），依本專案規則屬「異動較大」要先投票 |

欄位草案（單字）：`正面(漢字)` / `讀音` / `中文意思` / `例句` / `例句假名` / `例句中譯` / `tags(級別、來源)`
欄位草案（文法）：`句型` / `意思` / `接續` / `例句` / `例句中譯` / `tags`

- 匯出檔能被 Anki 桌機版直接匯入，欄位對應正確、日文與中文不亂碼（UTF-8）
- 匯出不改動任何 IndexedDB 資料
- audit 補斷言：匯出內容筆數＝所選範圍筆數、TSV 欄位數固定、含 tab／換行的欄位有正確跳脫
