## 清單

### A. 安裝與離線（iOS Safari、Android Chrome 各一次）
1. 用瀏覽器開網址，首頁正常顯示。
2. 加入主畫面後，從主畫面圖示開啟，畫面是全螢幕（沒有網址列）。
3. 用過首頁、學習、測驗各一次後，開飛航模式，從主畫面重開：首頁、各級測驗、生活旅行閃卡、統計頁都能用。
4. 關掉飛航模式，完全關掉 App 再開兩次，確認跑到最新版：學習頁的進度卡要看得到「學習中 N」與淺色進度段（v1.13.0 才有）。
   **不要看頁尾版號**：統計頁頁尾是寫死的字串，不管有沒有更新都顯示 v1.9.0（已知問題，見 STATUS §11）。

### B. 學習進度保存
5. 練一輪 20 題 → 完全關掉 App → 隔天再開：「學習中」數字還在、首頁顯示「有 N 項待複習」。
6. **加入主畫面開啟**與**瀏覽器分頁開啟**的進度是否互通？（iOS 上兩者的儲存空間可能是分開的，這點要特別確認並告訴 Yolin。）
7. 統計頁 → 匯出學習資料，檔案能下載並打開看到 JSON。
7a. **（v1.14.0 新增，優先度最高的一項）iOS 從主畫面開啟（standalone）時按匯出，檔案到底存不存得下來？**
   請在 iPhone 上「加入主畫面 → 從主畫面圖示開啟 → 統計頁 → ⬇️ 匯出學習資料」，
   確認**真的拿得到一個可以打開的 JSON 檔**（存到檔案 App 或分享出去都算），並回報過程中看到什麼。
   **為什麼這一項最重要**：匯出用的是 `a.click()` 下載 Blob。如果 iOS 主畫面模式**靜默失敗**
   （沒有存成檔案、也不丟任何錯誤），程式會以為匯出成功而寫入 `lastExportAt`，
   **備份提醒卡就會被錯誤地消掉、而且接下來 14 天都不再出現**——
   等於備份提醒在最需要它的情境（iOS、使用者以為自己備份過了、實際上沒有）反而失效，比沒有這個功能更糟。
   開發環境測不出這一點（headless 收不到 iOS 的行為），只能請 Yolin 實測。
   若結果是靜默失敗，要回頭改成「先確認檔案真的產生（或改用分享 sheet）才寫 `lastExportAt`」。
7b. 同一台 iPhone 上，用 Safari 分頁開同一個網址再按一次匯出，比較兩者行為是否相同（standalone 與分頁可能不一樣）。

### C. 聽力與朗讀（最需要真機驗證的部分）
8. 進「聽力練習」：是出現題目與 ▶ 按鈕，還是出現「這台裝置沒有日文語音」的安裝說明？
9. 若有題目：按 ▶ 有沒有聲音？第二題開始會不會自動播放？🐢 慢速有沒有變慢？
10. 若按了沒聲音：有沒有出現「沒有聽到聲音？」的提示與「顯示日文原文」？
11. Android：若一開始沒有日文語音，照畫面教學下載後按「🔄 裝好了，重新偵測」，能不能開始聽力。
12. 閃卡的 🔊 朗讀、統計頁的朗讀語速滑桿（調整後會試聽一句）是否正常。

### D. 模擬考
13. 快速版模擬考從頭做到尾：倒數計時、題號導覽、跳題、改答案、時間到自動交卷、結果頁。
14. 做到一半切到別的 App 再回來，計時是否合理（背景時 JS 計時器可能被系統暫停，這點沒驗證過）。

### E. 版面
15. 小螢幕（約 360px 寬）與平板上，各頁沒有左右捲動、文字沒有被切掉；深色模式下文字看得清楚。
