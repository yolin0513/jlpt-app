## 一句話

新增一種練習：題目顯示一個字的中文意思，下面是一堆假名方塊（正確讀音拆開的每一個假名＋幾個干擾的），使用者照順序點出讀音，排完自動判對錯。**全程只用點的，不開鍵盤、不打字。**

## 1. 現況

- 全 App 沒有任何打字輸入。題型：四選一（意思）、漢字讀音（`qtype=reading`）、例句填空（`qtype=cloze`）、聽力、模擬考；閃卡另一頁。題型掛在 `js/qtypes.js`，`quiz.js` 用 `buildSession` 的 `filter` 篩掉不適用的題。
- 單字每一筆都有 `kana`（讀音）、`kanji`、`meaning`、`romaji`，2,671 筆無缺。
- 只有 `qtypes.js` 裡一個私有的 `toHira()`（片假名→平假名）；沒有公用的假名處理函式。
- 學習頁（`learn.js`）用 `start('quiz', { qtype })` 帶出特殊題型；audit [19] 守著「入口參數有帶進網址」。

## 2. 目標與非目標

**目標**：G1 手機上順手——方塊夠大、點得準、點錯能退；G2 判定沒有灰色地帶——不會把對的判成錯的；G3 答題結果照常進同一套 SRS 進度。

**非目標**：不做鍵盤輸入（日文鍵盤或羅馬字）——之後若要當進階模式再說，這一份不預留；不出「變化形」的題（等詞性變化的資料補完）；不動題庫資料與備份格式；文法、旅行短句不出這種題（太長）。

## 3. 規則

- **R1 入口**：學習頁特殊題型那一區多一顆「拼寫練習」（與「漢字讀音」「例句填空」並列），走 `start('quiz', { qtype: 'spell' })`。只在 `type === 'vocab'` 時顯示。會吃 `SPEC_詞性篩選.md` 的詞性篩選（兩個條件同時成立）。
- **R2 哪些字會出題**：`kana` 拆成單位後長度在 **2–8** 之間的單字。1 個單位的沒得排；太長的方塊會塞滿畫面。各級適用的筆數寫進回報。
- **R3 怎麼拆假名（判定的核心，寫成一支公用的純函式）**：
  - 拗音的小字跟前一個假名黏成一個方塊：きゃ、しゅ、ちょ、ぎゅ…（ゃゅょ與片假名的ャュョ、ァィゥェォ）。
  - 促音「っ／ッ」、長音「ー」、撥音「ん／ン」各自是一個方塊。
  - 讀音裡若有非假名的字元（括號、「・」、「〜」、空白）→ 這個字不出題（歸到 R2 的不適用），不要試著清掉再出。
  - 平假名的字用平假名方塊、片假名的字用片假名方塊，**照題庫原樣，不轉換**（片假名外來語本來就該用片假名排）。
- **R4 題目畫面**：上方顯示中文意思（`meaning`）與詞性小標；**不顯示漢字**（多數漢字會洩漏讀音的長度與線索；而且這題練的是「會不會唸」）。中間是答案列（幾個空格＝幾個單位，空格數看得到）。下方是方塊區：正確的單位＋干擾單位，隨機排列。
- **R5 干擾方塊**：數量＝`max(3, 正確單位數的一半，無條件進位)`，總方塊數不超過 12。挑法要有鑑別度：優先放「容易混淆的」——同一行的假名（か↔が↔け）、清濁半濁（は↔ば↔ぱ）、長得像的（さ↔ち、ぬ↔め、シ↔ツ、ソ↔ン）、拗音換母音（きゃ↔きゅ↔きょ）；不夠再從同級其他單字的假名裡抽。**干擾方塊不得讓另一種排法也成為這個字的合法讀音**——最簡單的保證：干擾單位都不在正確答案的單位集合裡。正確答案自己有重複的單位（例如「ここ」）→ 方塊照實出現兩個。
- **R6 操作**：點方塊 → 填進下一個空格、該方塊變成已用；點答案列裡的方塊 → 退回方塊區（任何位置都能退，不是只能退最後一個）；全部填滿 → 自動判定（不必再按送出）。判定只有一種比對：**排出來的單位序列與 R3 拆出來的序列逐一相同**。
- **R7 回饋**：答對 → 顯示完整的單字卡資訊（漢字、讀音、意思、例句，沿用既有答題後的呈現）並可朗讀；答錯 → 標出哪幾格錯了、顯示正確讀音，然後同樣顯示單字卡。不做「再試一次直到對」——一題一次，錯了照 SRS 的規矩之後再出現。
- **R8 SRS**：答對／答錯寫進同一份進度，分數對應請沿用「漢字讀音」題的做法（它也是考讀音）；若你判斷拼寫比四選一難、該有不同的對應，先回報，不要自己定。
- **R9 無障礙與手機**：方塊的點擊區至少 44×44 px；375px 與 360px 寬不溢出、不需要橫向捲動；方塊是真的按鈕（鍵盤可操作、有 `aria-label`）；字級跟著既有的設定走。深色模式照舊。
- **R10 空池與邊界**：篩完沒有適用的字 → 走既有的空池畫面；一輪的題數不夠 → 有幾題出幾題。
